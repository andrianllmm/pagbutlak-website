# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, please **do not open a public GitHub issue**.

Instead, report it privately by emailing **pagbutlak.dev@outlook.com** with:

- A description of the vulnerability
- Steps to reproduce the issue
- The potential impact
- Any relevant screenshots or proof of concept (if available)

We will acknowledge your report within **7 days** and investigate the issue. If the report is accepted, we will work on a fix and coordinate responsible disclosure before publicly sharing details. If the report is determined not to be a security vulnerability, we will explain our reasoning and close the report.

We appreciate your efforts to responsibly disclose security issues and help keep Pagbutlak and its users safe.
